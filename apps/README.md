# Apps

Directorio reservado para aplicaciones desplegables independientes.

Objetivo:

- `apps/powerfit360` — PowerFit360
- `apps/cps` — Combat Performance System

Durante la migración inicial, el código actual de PowerFit360 permanece en su ubicación original para no afectar producción. El movimiento físico a `apps/powerfit360` se hará solo después de validar build, variables de entorno y despliegue.
